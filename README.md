# ROVS Productions

Cinematic portfolio site for ROVS Productions. Built with Vite, React, TypeScript, and Tailwind CSS.

## Local development

```sh
npm install
npm run dev
```

The dev server runs at http://localhost:8080.

## Production

```sh
npm run build
```

Deploy the `dist` output on Vercel. Client-side routes are rewritten to `index.html`.
